    Marginalia — quick guide

    What this tool is for

    Read your project's markdown docs in one place, mark passages you want to review, add inline comments, and export the whole batch of notes back to Claude for follow-up.

    Add a comment

    1. Open a doc from the left sidebar.
    2. Select any passage (at least a few words) in the reader.
    3. A floating 💬 Add comment button appears near the cursor.
    4. Click it, type your note, save. The passage is highlighted; the card lands in the right sidebar.

    Export & send to Claude

    • Hit Export (top right or Ctrl+S).
    • Choose JSON (structured for the AI) or Markdown (human-readable).
    • Copy to clipboard, or Download the file, or use Save to project (writes directly to .claude/scratchpad/ if you granted folder access — Claude then reads it without a paste step).
    • Or: if you have Chrome DevTools MCP connected, just tell Claude "read my Marginalia comments" — it can grab them from the tab's localStorage directly.

    Live mode & refresh

    • ↻ Refresh button reloads the doc bundle (comments are preserved via localStorage).
    • 🔗 Connect to a docs folder to switch on Live mode. The page then reads .md files directly from disk, so refresh always shows the current file contents. Uses the File System Access API (Chrome / Edge; other browsers stay on bundled mode).
    • Connecting grants read + write, so the in-app editor can save straight back to disk.
    • Rebuild the HTML from scratch by re-running the skill (or npx @sync667/marginalia).

    Editing a doc

    • ✎ Edit (or Ctrl/Cmd+E) opens the markdown editor for the current doc.
    • Use the section dropdown in the editor toolbar to work on one heading at a time instead of the whole file — picking ## Install shows just that section and its subsections. Your edit is merged back into the full document on save.
    • Ctrl/Cmd+S saves. With Live mode connected the file is written in place; otherwise you get a save dialog or a download.
    • Unsaved work is kept as a draft in localStorage, so closing the editor won't lose it.

    Comment lifecycle

    • ✎ edit inline · ✓ mark resolved · ⊘ dismiss · ↺ reopen · 🗑 delete.
    • Filter tabs: This doc / All docs / Open.
    • Click any comment's quote in the right sidebar to jump to it in the reader.

    Keyboard shortcuts

    Ctrl/⌘+K Focus search Ctrl/⌘+S Open export dialog Ctrl/⌘+R Refresh docs (in Live mode) Ctrl/⌘+/ Open this help (works while typing) ? Open this help (when not typing in a field) Esc Close modal / dismiss popover Ctrl/⌘+Enter Save comment (inside modal)

    Privacy

    Nothing is uploaded. Comments live in your browser's localStorage, keyed by a hash of the docs directory path so switching projects gives you a fresh workspace.
